# 🎄 Árvore de Natal em C

Programa em linguagem **C** que imprime uma árvore de Natal em ASCII no console.
O usuário pode escolher os caracteres internos da árvore e o programa exibe
uma mensagem final de boas festas.

Projeto simples, voltado para **prática de lógica**, **laços de repetição** e
**formatação de saída no terminal**.

---

## ✨ Funcionalidades

- Desenha uma árvore de Natal em ASCII
- Permite escolher os caracteres internos da árvore
- Exibe mensagem centralizada de **Feliz Natal e Ano Novo**
- Executado diretamente no terminal

---

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Compilador GCC (MinGW)
- Execução em terminal (Windows)

---
